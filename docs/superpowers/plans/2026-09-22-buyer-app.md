# Mei启蒙买家版App 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把谦灵启蒙App改造成可售的买家版——买家扫码进App看到自家娃名字和定制内容，打卡自动同步给Mei，Mei有教师端面板看所有家庭。

**Architecture:** 新仓库 meiyanjie1990/mei-qimeng（GitHub Pages + GitHub Contents API，零服务器）。买家经 `?f=<家庭码>` 进入，前端加载基础内容库（谦灵48周内容）+ 家庭覆盖层（娃名字、起始日期、个性化修改），打卡写本地并同步到 checkins.json（按家庭隔离）。教师端 teacher.html 用老师码进入，展示所有家庭进度与掉队标记。

**Tech Stack:** 纯前端单页无构建（index.html + logic.js + ui.js + content.json），node:test 测试，PWA + Service Worker，GitHub Contents API 同步（五人打卡同款模式）。

## Global Constraints

- 品牌名「Mei的英语启蒙」；PWA 名「Mei启蒙」；页面标题动态显示「{娃名}的启蒙」
- **年龄不限（1.5岁以上），内容按年龄设计**：与谦灵轨（2.5-4岁）差距大的家庭，覆盖层支持整周替换（`overlay.weeks`），入职时AI起草定制周（前4周全量+骨架），随每周出课节奏补全
- 森林手账视觉：霞鹜文楷手写体（fonts/ 本地子集）+ 五色纸卡 + 缝线卡片，米白底 #F6F1E6（照抄谦灵App v7）
- 买家版**不显示**谦灵课表的固定日历日期；改为「第N周 + 按家庭起始日期算出的日期范围」
- 谦灵App仓库一行都不能动；内容复用通过 `tools/sync-content.js` 单向拷贝
- 手机端App通则照做：真 button、全局禁选字（`button,[data-action]{user-select:none;...}`）、清完缓存再 reload
- GitHub Pages 必须走 workflow 部署（`.github/workflows/pages.yml`），新仓库用分支构建会卡死
- 仓库 remote 用 SSH（git@github.com），https 推送会被重置
- 发布铁律：`node --test` 全绿 → bump version.json + sw.js CACHE_NAME（页面代码改动时）→ push → `curl -s -o /dev/null -w "%{http_code}" https://meiyanjie1990.github.io/mei-qimeng/` 返回 200 才算发布成功
- GitHub Token 安全：只放**一个** fine-grained PAT，权限只给本仓库 contents:write（checkins.json 单文件仍受限制于 API 粒度，接受此债务并写入 CLAUDE.md 迁移路径）；Token 单独放 `config.js`（.gitignore 排除，通过 Pages workflow secret 注入或部署前手工写入——v1 用构建脚本注入，见 Task 8）

```js
Logic.parseFamilyCode = function () {
  const m = (location.search || "").match(/[?&]f=([A-Z0-9]{6})/i);
  return m ? m[1].toUpperCase() : null;
};

Logic.loadRegistry = async function () {
  const r = await fetch("families.json?ts=" + Date.now());
  if (!r.ok) throw new Error("registry load failed");
  return r.json();
};

Logic.loadOverlay = async function (code) {
  const r = await fetch("families/" + code + ".json?ts=" + Date.now());
  return r.ok ? r.json() : null;
};

Logic.mergeContent = function (base, overlay) {
  if (!overlay) return base;
  const weeks = base.weeks.map(function (w) {
    const key = String(w.week);
    if (overlay.weeks && overlay.weeks[key]) return overlay.weeks[key]; // 整周替换优先
    const o = overlay.overrides && overlay.overrides[key];
    let wk = w;
    if (o && o.extraWords) wk = Object.assign({}, wk, { coreWords: wk.coreWords.concat(o.extraWords) });
    if (overlay.themeSwaps && overlay.themeSwaps[key]) {
      wk = Object.assign({}, wk, { theme: overlay.themeSwaps[key] });
    }
    return wk;
  });
  return Object.assign({}, base, { weeks: weeks, childName: overlay.childName });
};

Logic.currentWeekNumber = function (startDate, today) {
  const start = new Date(startDate + "T00:00:00");
  const diffDays = Math.floor((today - start) / 86400000);
  return Math.min(48, Math.max(1, Math.floor(diffDays / 7) + 1));
};

Logic.weekDateRange = function (startDate, weekNumber) {
  const start = new Date(startDate + "T00:00:00");
  start.setDate(start.getDate() + (weekNumber - 1) * 7);
  const end = new Date(start);
  end.setDate(end.getDate() + 6);
  const fmt = d => d.toISOString().slice(0, 10);
  return { start: fmt(start), end: fmt(end) };
};
```

```js
  const families = Object.assign({}, remote.families || {});
  families[code] = Object.assign({}, families[code], { checkins: local });
  return { families: families };
};

Logic.pushCheckins = async function (code, local) {
  for (let attempt = 0; attempt < 5; attempt++) {
    const get = await fetch(REMOTE_URL + "checkins.json?ts=" + Date.now());
    let sha = null, remote = { families: {} };
    if (get.ok) { const d = await get.json(); sha = d.sha; remote = JSON.parse(atob(d.content)); }
    const merged = Logic.mergeCheckins(remote, code, local);
    const put = await fetch(REMOTE_URL + "checkins.json", {
      method: "PUT",
      headers: { "Authorization": "token " + token(), "Content-Type": "application/json" },
      body: JSON.stringify({ message: "checkin " + code, content: btoa(unescape(encodeURIComponent(JSON.stringify(merged)))), sha: sha })
    });
    if (put.ok) return true;
    if (put.status !== 409 && put.status !== 422) return false; // 422=sha 不匹配
  }
  return false;
};
```

（`token()` 读全局 `window.CONFIG.GITHUB_TOKEN`；`btoa/atob` 中文问题用 `unescape(encodeURIComponent(...))` 包一层，照五人打卡的做法。）
